# Litterbug - Mobile Interaction Design & Behavioral UX Research Case Study

## 📋 Project Overview
Litterbug is a mobile interaction design and civic engagement concept built to encourage community environmental action. The application uses behavioral design patterns to turn neighborhood cleanup efforts into an engaging, habit-building experience.

The main goal of this project was to design an interface that makes reporting environmental issues as quick and seamless as possible, using core psychological frameworks to keep users motivated and involved over the long term.

---

## 🔬 User Psychology & Visual Layout Principles Applied
The interface layout and navigation paths for Litterbug were developed and evaluated using standard human-computer interaction (HCI) and visual perception guidelines:

### 1. Driving Motivation Through the "3Cs Framework"
To guide users from passive observers to active community contributors, the platform’s core features were structured around three baseline elements of motivation:
* **Competence (Building Confidence):** Designed straightforward onboarding workflows and simple progress metrics to give users an immediate sense of milestone tracking and success when completing cleanups.
* **Autonomy (Giving Control):** Created flexible navigation menus and task management choices, letting users decide how and when they want to participate without forcing them down a rigid, restrictive path.
* **Relatedness (Connecting People):** Implemented local community updates, group goal-tracking, and clear neighborhood indicators to foster a shared sense of team effort and ecological purpose.

### 2. Organizing Maps & Dashboards via Gestalt Principles
To optimize the live mapping features and ensure the dashboard is easy to scan, interface components were grouped using standard visual laws:
* **Grouped Data (Law of Proximity):** Placed related status updates, location pins, and report buttons inside clean, connected visual containers so users can read the layout instantly.
* **Consistent Categories (Law of Similarity):** Standardized visual icons and color codes across pins so users can automatically recognize different types of environmental issues at a single glance.
* **Guiding the Eye (Visual Focus):** Calibrated contrasting color choices to balance **Goal-Directed Focus** (what the user wants to do) and **System-Driven Prompts** (critical notifications), ensuring users never miss important updates on crowded screen maps.

## 🛠️ Research Steps & Project Sprint Lifecycle
The user research phase for Litterbug followed a realistic four-week project timeline to simulate a rapid industry development cycle:

* **Week 1 (Scoping & Goals):** Defined the user-centered design (UCD) research targets and mapped out the initial boundaries of the user journey.
* **Week 2 (Planning & Session Design):** Created interactive task scenarios and drafted unbiased screening filters to select our user testing pool.
* **Week 3 (User Testing Sessions):** Conducted live, moderated user tests using the **Think-Aloud Protocol** to capture natural behavior, watching exactly how users navigated through spatial information and map screens.
* **Week 4 (Grouping Data & Reporting):** Organized qualitative user feedback into a clear affinity diagram to spot recurring patterns, prioritizing layout fixes based on where users experienced the most friction.
